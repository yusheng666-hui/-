# 界面设计

## 页面结构

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | 首页 | 对话列表 / 直接进入聊天 |
| `/chat/[id]` | 聊天 | 核心聊天页（含快捷回复、反刍提示、往事回顾、急救按钮） |
| `/settings` | 配置 | API Key、主题颜色、人格选择、偏好置信度面板、隐私、语音克隆、急救按钮开关 |
| `/memories` | 记忆管理 | 查看/编辑/删除记忆 |
| `/insights` | 情绪洞察 | 情绪日历、本周简报、AI 模式发现、成长卡片、偏好学习进度 |
| `/outputs` | 产出管理 | AI 生成的草稿（回信/决策卡/日记等） |

## 首次启动引导（已实现）

启动时自动弹出三段式新手引导，覆盖在首页之上，完成保存到 Profile 不再重复显示。
用户也可在首页底部手动点击「新手引导」重新打开。

| 页 | 内容 |
|----|------|
| 1 | 🧠 "我先思考，再回你" |
| 2 | 📊 "你越用，我越懂你" |
| 3 | 📝 "想安静的时候，开日志模式" |

## 聊天页（核心）

### 布局
- **顶部**：极简标题 + 模式切换（聊天/日志/低电量/急救）；学习阶段徽章
- **主体**：聊天气泡列表，新消息自动滚动到底部

### AI 主动开场
进入聊天页时，如果距上次对话超过 6 小时，显示开场横幅：
"上次你提到...——后来有变化吗？" 
首次使用时显示："嗨，我是你的情绪共生体..."
用户可直接点击发送或关闭。

### 快捷回复
AI 回复完成后，气泡下方横向显示快捷回复芯片（3-4 个），点击即发送：
- 聊天模式："嗯，继续说" / "我懂了" / "换个话题" / "今天就这样"
- 急救模式："好一点了" / "还是很难受" / "不想说了"
- 低电量："说完了" / "明天聊" / "晚安"

### 沉默许可
AI 回复 8 秒后，输入框上方显示细小的"说完了就不用说了，在这里待一会儿也行"，5 秒后自动消失。

### 反刍识别提示
AI 检测到用户反复纠结同一负面话题时，在输入框上方显示提示横幅：
🔄 "注意到你在反复想同一件事" + 具体描述 + 换个角度建议。
10 秒后自动消失，可手动关闭。

### 往事回顾
AI 检索到历史记忆时，在输入框上方显示淡提示条：
💭 "提到了一件往事..." + 匹配的记忆摘要。
5 秒后自动消失。

### 对话结束感
AI 检测到对话自然结束时（用户说"好了""晚安""先这样"等），
自动生成今日小结卡片，包含话题总结和告别语。输入框暂停 5 秒。

### 情绪速记
输入框左侧 😊 按钮，打开全屏 6 格情绪选择器：
❤️难受 / 😔有点丧 / 😐一般般 / 😊还不错 / 🤗很赞 / 😤烦躁
选完即保存到本地，不触发 AI 回复。

### 空状态话题引导
首次进入聊天页时，随机展示 4 个话题卡片引导对话：
"今天有什么小事让你烦了一下？" / "刚才刷到一条让你想吐槽的？" / 共 10 个话题轮换
底部显示 🤷 "不知道说什么" 按钮，点击后 AI 主动引导。

### Action Loop 反馈
AI 回复中有微行动建议时，气泡下方显示反馈按钮：
```
[去倒杯水喝]
✅做了    😅没做
```
点击后反馈写入 action_logs。

### 情绪急救浮动按钮
所有页面右下角悬浮 🫂 圆按钮，点击跳转 `?mode=emergency`。
可随时关闭（设置页开关）。聊天页/设置页自动隐藏。

### 气泡渲染规则

| 角色 | 对齐 | 样式 |
|------|------|------|
| User | 右对齐 | 主题强调色背景 / 白色文字 |
| Thought | 左对齐 | 主题 surfaceLight 背景 / 灰色文字，🧠 前缀 |
| Assistant | 左对齐 | 主题 surface 背景 / 主题 text 色 |

### 流式体验
- 自定义 SSE Stream 解析，逐 data 事件追加文本（打字机效果）
- Thought 气泡完整渲染，Assistant 气泡逐步追加

## 配置页（/settings）

### 主题颜色
6 套主题可选：纯白、暖白、柔粉、深空紫（默认）、暖阳橙、AMOLED纯黑。
选择器以圆框色块形式展示，选中时高亮边框。

### API 配置
- API 类型：Anthropic / OpenAI 兼容
- API 地址（默认根据类型切换）
- 模型名称（默认根据类型切换）
- API Key：expo-secure-store 加密存储

### 学习进度
显示学习阶段徽章 + 累计对话次数。

### 沟通偏好面板
6 维偏好置信度进度条：语气风格/建议方式/直言接受度/幽默程度/分析深度/情感表达

### AI 人格预设
树洞 / 损友 / 长辈 / 战友，切换不影响记忆和偏好。

### 显示控制
- 🧠 显示思考过程（开关）
- 🫂 情绪急救按钮（开关）

### 语音回复
- 启用 / 自动朗读开关
- TTS 供应商：系统 TTS / OpenAI TTS / 我的声音（语音克隆）
- 语音参数：语速 / 音调 / 音量

## 记忆管理页（/memories）

按分类和情绪标签筛选；搜索；编辑/删除/调整权重。

## 情绪洞察页（/insights）

### 情绪日历
过去 4 周 GitHub 风格热力图，6 种情绪颜色映射，
点击某格查看当日情绪详情，底部显示"本月已签到 X 天"。

### 本周简报
统计卡片：对话次数 / 成长时刻 / 主要情绪 / 高频话题。

### 本周心情
过去 7 天心情表情行。

### 数据概览
总对话 / 总记忆 / 成长时刻。

### 本周活动
过去 7 天每日对话频次柱状图。

### 情绪分布
记忆中最常被标记的情绪条形图。

### AI 模式发现
基于 Topics 数据自动检测反复出现的话题。
每条显示：关键词 + 情绪标签 + 出现次数。
点击可查看关联的记忆列表。

### 偏好学习进度
6 维偏好当前置信度条形图（< 30% 灰色 / 30-70% 强调色 / > 70% 绿色）。

### 成长时刻
2 列卡片网格，按时间倒序显示成长里程碑（自我发现/应对成功/积极转变/模式突破/新视角）。

## 产出管理页（/outputs）

按时间倒序展示 AI 生成的回信草稿、决策卡、日记等。
