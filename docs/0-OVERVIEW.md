# 产品定位与核心原则

## 目标用户

孤独、内耗、渴望被理解但又害怕社交的年轻人。

## 核心定位

纯个人情绪陪伴工具，人与 AI 深度共生，绝对不含任何社交功能。

## 四大核心原则（绝对不可违背）

### 1. 透明思考
AI 绝不能直接回复用户。必须先输出思考分析过程，让用户看到 AI 是如何理解他的。

### 2. 自我进化（核心差异）
AI 必须从每次对话中持续学习，越用越懂用户：

- **每轮学习** — 每次对话后自动分析用户的反馈信号，实时调整偏好
- **多维适配** — 在语气、建议方式、直言接受度、幽默感等六个维度上动态校准
- **词汇镜像** — 学习和复用用户自己的情绪表达词汇（用户说"糟心"，AI 也用"糟心"）
- **模式识别** — 发现情绪触发的时间/场景/人物规律，适当时机自然指出
- **话题延续** — 跨对话追踪反复出现的话题，让对话有连续性
- **成长感知** — 识别用户的进步时刻（自我发现、应对成功、积极转变）并记录为成长里程碑
- **人格成长** — 积累足够偏好记忆后，主动建议用户更新人格底色

区别于简单的记忆存储，这套机制让 AI **每次回复都在学习"这样回到底对不对"**，从而在 10~20 次对话内就能较为准确地贴合用户风格。

目标是：用户越用，越觉得"它真的懂我"。

### 3. 用户绝对掌控
用户可以随时查看、修改 AI 的所有底层数据（人格设定、记忆、自定义动作）。AI 不是黑盒，一切可追溯、可干预。

### 4. 零服务端优先
App 核心功能无后端服务，全部数据存储在手机本地（AsyncStorage）。API Key 由用户自行配置，App 直接调用 LLM 供应商接口（Anthropic 或 OpenAI），不经过任何代理服务器。

可选的外部服务：
- **语音克隆** — 用户可选择部署开源的 OpenVoice v2 服务器到 Hugging Face Spaces（免费），App 调用该服务器合成用户声音。这是一项可选功能，默认关闭。服务器地址由用户自行配置，App 不绑定任何预设服务。

## 进化路线图

| 阶段 | 名称 | 能力 |
|------|------|------|
| 一 | 基础对话 | 透明思考 + 本地记忆存储 + 自定义动作 + 多 API 支持（Anthropic/OpenAI） |
| 二 | 主动学习 | 情绪模式识别 + 权重进化 + 多维偏好适应（tone, advice_style, confrontation_comfort 等六维）+ 每轮反馈闭环 |
| 三 | 深度共生 | 新手引导 / 快捷回复 / 话题引导 / 反刍识别 / 往事回顾 / AI 模式发现 / 本周简报 / 沉默许可 / 三件好事 / 连续签到 / 主动洞察 + 情绪日历 + 情绪速记 + Grounding 练习 + 学习阶段演进 + 词汇镜像 + 话题延续 + 成长卡片 + 对话结束感 + AI 主动开场 + Action Loop + 微任务处理 + 情绪急救浮动按钮 + 语音克隆（OpenVoice v2）+ 数据导出 / 待实现：手机端（系统分享/通知/小组件/App Shortcuts/锁屏打卡/专注模式联动）|
